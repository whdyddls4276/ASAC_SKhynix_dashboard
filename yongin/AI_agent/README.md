## 1. 사전 준비

### Python 패키지 설치

```bash
cd sk-dashboard/AI_agent
pip install -r requirements.txt
```

### API 키 설정

`sk-dashboard/.env` 파일에 Gemini API 키를 입력합니다.

```env
GEMINI_API_KEY=여기에_본인_API_키_입력
```

> Gemini API 키 발급: https://aistudio.google.com/apikey (무료)  
> 무료 플랜 기준 하루 약 20~50회 요청 가능 (UTC 자정 초기화)

---

## 2. 서버 실행

`AI_agent/start.bat` 파일을 **더블클릭**합니다.

- 터미널 창 2개가 자동으로 열립니다.
  - 백엔드 서버 (포트 8080)
  - 프론트엔드 서버 (포트 7700)
- 두 창 모두 열린 상태를 유지해야 합니다. **닫으면 서비스가 중단됩니다.**

### 수동 실행 (start.bat이 안 될 때)

터미널을 2개 열고 각각 실행합니다.

**터미널 1 — 백엔드**
```bash
cd sk-dashboard/AI_agent/backend
python -m uvicorn main:app --reload --port 8080
```

**터미널 2 — 프론트엔드**
```bash
cd sk-dashboard/AI_agent/frontend
python -m http.server 7700
```

## 3. 대시보드 열기

서버 실행 후 브라우저에서 아래 주소로 접속합니다.

| 페이지 | 주소 |
|--------|------|
| **AI 에이전트 대시보드** | http://localhost:7700/dashboard.html |
| **분석 보고서 (AI 수정 가능)** | http://localhost:8080/ui/report_v2.html |

### 대시보드 구성

`dashboard.html` 화면에는 다음 정보가 표시됩니다.

| 항목 | 내용 |
|------|------|
| VAL RMSE / Test RMSE | 모델 예측 오차 |
| 분류기 RECALL / PRECISION | 고위험 유닛 탐지 성능 |
| 고위험 유닛 수 | clf_proba 기준 고위험으로 분류된 유닛 |
| FN RMSE | 고위험을 놓쳤을 때의 예측 오차 |
| 유닛 위험도 분포 | 고위험(0.4+) / 중위험(0.2~) / 저위험(0~0.2) 분포 |
| 분류기 성능 요약 | Recall, Precision, FN/FP RMSE, FN/TP 수 |
| 상위 위험 피처 Top 15 | 잔차 예측 중요도 기준 상위 피처 목록 |

## 4. AI 에이전트 챗봇

대시보드 우측 하단의 **파란 원형 버튼**을 클릭하면 챗봇이 열립니다.

### Agent 탭

실제 모델 데이터를 조회해서 답변합니다.

**사용할 수 있는 도구 4가지:**

| 도구 | 언제 쓰이나 |
|------|------------|
| 모델 성능 조회 | RMSE, Recall, Precision 질문 |
| 위험도 분포 조회 | 고위험 유닛 수, 비율 질문 |
| 상위 위험 피처 조회 | 어떤 피처가 불량에 영향을 주는지 질문 |
| 지식 베이스 검색 | 반도체 용어, DRAM 도메인 개념 질문 |

**질문 예시:**
```
현재 모델 성능이 어때?
고위험 유닛이 몇 개야?
가장 중요한 피처 5개 알려줘
RMSE가 뭔지 설명해줘
```

### Assistant 탭

반도체·DRAM 도메인 지식을 검색해서 답변합니다. (RAG 기반)

**질문 예시:**
```
WT(Wafer Test)가 뭐야?
RCC는 어떻게 측정되나요?
Two-Stage 모델이 뭔가요?
SHAP 값이 뭔지 설명해줘
```

> Agent와 Assistant는 **대화 히스토리를 유지**합니다. 이전 답변을 이어서 질문해도 됩니다.

## 6. 보고서 AI 수정

보고서 우측 하단 채팅창에서 **자연어로 수정 명령**을 입력합니다.

### 수정 명령 예시

| 명령 | 결과 |
|------|------|
| `SHAP 상위 5개만 보여줘` | SHAP 차트가 5개 항목으로 줄어듦 |
| `트렌드 최근 1주일만 보여줘` | 트렌드 차트 날짜 범위 필터링 |
| `Wafer 불량률 50% 이상만` | Wafer 위험 테이블 필터링 |
| `피처 중요도 10개로 줄여줘` | 피처 목록 10개로 축소 |
| `분석 코멘트 추가해줘` | 보고서 하단에 AI 분석 코멘트 추가 |
| `피처 중요도 새 Bar 차트 추가해줘` | 새 차트 섹션 생성 |

### 수정 초기화

우측 상단 **"초기화"** 버튼을 누르면 보고서가 원본 상태로 돌아갑니다.

> 수정 내역은 서버가 실행 중인 동안만 유지됩니다. **서버를 재시작하면 초기화**됩니다.

## 7. PPT 다운로드

보고서 페이지 우측 상단 **"PPT 다운로드"** 버튼을 클릭합니다.

- AI 수정이 반영된 현재 상태 그대로 PPT가 생성됩니다.
- 모든 차트는 PPT에서 직접 편집 가능한 네이티브 차트로 생성됩니다.
- 파일명: `field_health_report_날짜_시간.pptx`

### PPT에 포함되는 내용

- 헤더 배너 (날짜, RMSE, 대외비)
- 불량률 트렌드 라인 차트
- SHAP 분석 바 차트
- 위험 집중 Wafer 테이블
- 고위험 피처 박스플롯
- 개선 방안 시뮬레이션 테이블
- AI가 추가한 커스텀 차트 (있을 경우)

## 8. 자주 묻는 것들

**Q. 챗봇이 "Gemini API quota 소진"이라고 해요.**  
A. 무료 플랜 하루 요청 한도(약 20~50회)를 초과했습니다. UTC 자정(한국 시간 오전 9시) 이후에 다시 사용하거나, 유료 플랜으로 전환하세요.

**Q. 보고서 페이지가 빈 화면으로 나와요.**  
A. 백엔드 서버(포트 8080)가 실행 중인지 확인하세요. `start.bat` 터미널 창이 열려 있어야 합니다.

**Q. PPT를 다운받았는데 차트가 이상해요.**  
A. 보고서 AI 수정 챗봇으로 데이터를 크게 변경한 경우 레이아웃이 틀어질 수 있습니다. "초기화" 버튼으로 원본 상태에서 다시 다운받아 보세요.

**Q. start.bat을 실행했는데 포트 오류가 나요.**  
A. 이미 8080 또는 7700 포트를 사용 중인 프로세스가 있습니다. 터미널에서 아래 명령으로 확인 후 종료하세요.
```bash
netstat -ano | findstr :8080
taskkill /PID [PID번호] /F
```

**Q. Assistant 탭이 응답을 못 해요.**  
A. `rag_db/vectordb/` 폴더가 없거나 비어있으면 RAG 기능이 동작하지 않습니다. 벡터 DB 파일을 함께 받았는지 확인하세요.
