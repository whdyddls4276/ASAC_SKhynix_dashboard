## 2. AI Agent 백엔드

### 2-1. 기술 스택

| 항목 | 내용 |
|------|------|
| LLM | Gemini (google-genai 1.73.1 신규 SDK) |
| 서버 | FastAPI + uvicorn (port **8080**) |
| Tool Use | 수동 Function Calling 루프 (AutomaticFunctionCallingConfig disable) |
| 모델 Fallback | `gemini-2.5-flash-lite` → `gemini-flash-lite-latest` → `gemini-2.5-flash` → `gemini-2.0-flash-lite` |

### 2-2. Agent 도구 (4종)

| 도구명 | 설명 |
|--------|------|
| `get_performance_summary` | Val/Test RMSE, 분류기 Recall/Precision/F1 반환 |
| `get_risk_distribution` | 고위험/중위험/저위험 유닛 수·비율 반환 |
| `get_top_risk_features` | 잔차 분석 상위 피처 목록 반환 |
| `search_knowledge_base` | 반도체/DRAM 도메인 지식 DB 검색 (RAG) |

### 2-3. 해결한 버그

| 버그 | 원인 | 해결 |
|------|------|------|
| 포트 8000 연결 실패 | zombie TCP socket (PID 23304) | 포트 **8080**으로 변경 |
| `gemini-1.5-flash` not found | 모델 deprecated | `gemini-2.5-flash` 및 fallback 목록으로 교체 |
| 429 RESOURCE_EXHAUSTED | 무료 quota 소진 (20회/일) | 모델 fallback 루프 + 친절한 오류 메시지 |
| 도구 이름 불일치 | 모델이 `get_top_risk_features` 호출 시 `tool_` 접두사 있는 dict에서 못 찾음 | TOOL_FUNCTIONS에 두 버전 모두 등록 |
| `Part.from_text()` 오류 | 신규 SDK에서 인자 방식 변경 | `types.Part(text=h["content"])` 로 수정 |

### 2-4. API 엔드포인트

```
GET  /api/performance        → 모델 성능 지표
GET  /api/risk-distribution  → 위험도 분포
GET  /api/top-features       → 상위 피처
GET  /api/predictions        → 예측값 scatter용 샘플
POST /api/chat               → 챗봇 (히스토리 포함)
POST /api/chat/stream        → 챗봇 스트리밍
POST /api/report             → 분석 보고서 생성
GET  /api/report/stream      → 보고서 스트리밍
```

## 4. SHAP 분석 (신규 구현)

### 4-1. 방법론

| 항목 | 내용 |
|------|------|
| 방식 | **서로게이트 LightGBM + TreeSHAP** |
| 학습 데이터 | test 유닛 8,749개 × unit-level 집계 피처 500개 |
| 타겟 | y_pred (원 모델의 최종 예측값) |
| 서로게이트 R² | **0.7714** (원 모델 행동의 77% 설명) |
| SHAP 라이브러리 | `shap.TreeExplainer` (v0.51.0) |
| 피처 기반 | `res_importance_20-101-002.csv` TOP 500 (mean/std/min/max/median/range 집계) |

> **왜 서로게이트 모델?**  
> 원 모델은 Two-Stage 구조 (분류기 × 회귀기). 분류기 모델 객체가 pkl에 미저장 → 직접 SHAP 불가.  
> 서로게이트는 최종 y_pred를 직접 설명하므로 전체 파이프라인의 피처 기여도 파악에 더 적합.

## 5. React 대시보드 FeatureAnalysis 페이지

### 5-1. 탭 구성

| 탭 | 내용 | 데이터 소스 |
|----|------|------------|
| SHAP 분석 | effect_norm 수평 바 차트 + 피처 임포턴스 비교 | `shap_data.csv` |
| 분포 비교 | 드롭다운 피처 선택 → ECharts 박스플롯 (Q10~Q90) + 통계 카드 | `dist_data.csv` |
| 피처 임포턴스 | 랭크 scatter, consensus pie, gain vs impurity scatter | `feature_importance.csv` |

### 5-2. 대시보드 CSV 생성

```bash
cd 기업/5_agent
python make_shap_csv.py
# → Dashboard/public/shap_data.csv (20행: feature, effect_norm, lgbm_gain, ...)
# → Dashboard/public/dist_data.csv (40행: 20피처 × HIGH/MED 그룹 분포)
```

> **effect_norm 계산식 (대시보드용)**:  
> `(HIGH_median - MED_median) / global_std`  
> 실제 SHAP 아님. 그룹 간 정규화된 중앙값 차이.
