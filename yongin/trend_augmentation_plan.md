## 2. 구간 1: 합성 생성 (4개월 전 ~ 2개월 전)

실제 데이터 없이 **시각적으로 자연스러운 y값만 생성**.

### y_pred 생성
- Random walk + mean reversion 방식
- 기준값(BASELINE) = 71.0% (실제 수율 70.8% 기반)
- 매일: `val = val × 0.95 + 71.0 × 0.05 + N(0, 1.5)`, clip(63, 82)
- 결과: mean≈70.9%, std≈4.1%

### y_true 생성
- y_pred에 랜덤 노이즈 추가
- `y_true = y_pred + N(0, 3.0)`, clip(60, 85)
- y_pred 대비 ±3~5%p 벌어지는 수준

---

## 3. 구간 2: 실제 데이터 기반 증강 (2개월 전 ~ 오늘)

`dashboard_units.csv`의 실제 예측값을 사용하여 일별 수율을 생성.  
y_pred만 존재 (y_true 없음 — 실제 health 미공개 구간).

### Step 1: defect_thresh 계산
```
train split의 reg_pred를 오름차순 정렬
→ 70.8 percentile 값 = defect_thresh (≈ 0.003408)
```
- 의미: train 기준 상위 29.2%를 불량으로 정의

### Step 2: 웨이퍼 풀 구성
- 단위: `(run_id, wafer_no)` 조합
- 전체 웨이퍼 수: **1,292개** (train 431 + val 431 + test 430)
- 각 웨이퍼의 수율 = 해당 웨이퍼 unit 중 `reg_pred < defect_thresh` 비율 × 100

```python
wafer_pool = units.groupby(['run_id', 'wafer_no']).apply(
    lambda g: 100 * (1 - (g['reg_pred'] >= defect_thresh).mean())
)
```

### Step 3: 합성 로트 생성 (핵심)

**규칙:**
- 하루 10개 로트 생성 × 62일 = **총 620개 합성 로트**
- 합성 로트 1개당 웨이퍼 **25개** (복원추출)
- 같은 로트의 웨이퍼는 **3일 윈도우** 안에 랜덤 배정
  - 실제 공정에서 같은 로트 웨이퍼들은 비슷한 시기에 생산된다는 가정
- 로트번호 새로 부여 (1001번~, 기존 1~84와 겹치지 않게)

```
for 매일:
    for 10번:
        실제 로트 복원추출 (84개 중)
        → 해당 로트 웨이퍼에서 25개 복원추출
        → 25개를 [오늘, 오늘+1, 오늘+2] 중 랜덤 배정
        → 새 로트번호 부여
```

### Step 4: 일별 수율 계산
- 해당 날짜에 배정된 모든 웨이퍼의 수율 평균
- 하루 수신 웨이퍼 수: 약 10 lots × 25개 / 3일 ≈ **83개/일**
- 결과: mean≈73.9%, std≈5.3%

### Step 5: 구간 경계 블렌딩
- 구간 1 마지막값 → 구간 2 첫값이 자연스럽게 이어지도록 7일간 선형 보간

## 5. 대시보드 렌더링 (`Overview.jsx`)

- 데이터 소스: `trend_data.csv` (`useCSV` 훅으로 로드)
- 기존 lot별 집계 + `lotToDate()` 방식 → **CSV 직접 사용으로 교체**

| 요소 | 설정 |
|------|------|
| 예측 수율 | 파란 라인 (`#3B82F6`), 전 구간, `smooth: true` |
| 실제 수율 | 빨간 영역 (`#EF4444`), 구간 1만 (`connectNulls: false`) |
| 점선 경계 | y_true가 처음 null이 되는 날짜 = "예측 전용 구간" |
| y축 범위 | 50~100% |
| x축 레이블 | `interval: 6` (약 주 단위) |
| 줌 슬라이더 | 하단 dataZoom 슬라이더 + 마우스 휠 줌 |
